Virtual Microscope: Mitosis Lab (Canvas Package)

Files included:
- virtual_microscope_mitosis_canvas.html  -> self-contained interactive simulation
- assets/                                 -> original cropped images used to build the HTML

Recommended Canvas use:
1. Upload the HTML file to Files in your Canvas course.
2. Click the file once to verify that it opens and runs in a browser tab.
3. In a Canvas Page, you can either:
   A) create a link to the HTML file, or
   B) use an iframe that points to the uploaded HTML file URL.
4. Because Canvas Pages often sanitize JavaScript, the safest option is to launch the HTML file from Files (or embed the file URL in an iframe if your Canvas instance allows it).

Suggested iframe pattern (replace YOUR_FILE_URL with the Canvas file URL):
<iframe src="YOUR_FILE_URL" width="100%" height="1000" style="border:0;"></iframe>
